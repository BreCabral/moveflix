# 🎬 MoveFlix
Projeto didático desenvolvido como parte do curso Java10X, com o objetivo de simular uma API de armazenamento de informações sobre filmes e séries, nos moldes de uma plataforma como a Netflix.

## 🚀 Tecnologias Utilizadas
Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:

 - Java 17
 - Spring Boot 3
 - Spring Web
 - Spring Security
 - JWT (JSON Web Token)
 - Spring Data JPA
 - Bean Validation
 - PostgreSQL
 - Flyway (migrations)
 - Lombok
 - Tratamento de Exceptions
 - Swagger / OpenAPI (documentação da API)

## 📚 Sobre o Projeto
O MoveFlix API é uma aplicação backend RESTful que permite armazenar, consultar, atualizar e deletar informações sobre filmes e séries. Ele simula as funcionalidades básicas de um catálogo de streaming.

Funcionalidades principais:

 - Cadastro de filmes e séries
 - Listagem de títulos disponíveis
 - Busca por título
 - Atualização e remoção de registros
 - Segurança com autenticação JWT
 - Documentação interativa com Swagger

## 🧠 Objetivo Educacional
Este projeto tem fins didáticos e foi desenvolvido com o intuito de praticar e consolidar os conhecimentos adquiridos durante o curso Java10X, abordando desde a construção da API até a sua segurança, persistência e documentação.

## 🔒 Autenticação
A autenticação da API é feita por meio de JWT (JSON Web Token). Algumas rotas são públicas, enquanto outras requerem autenticação com token válido.
